
# 大模型量化

## 1. 为什么需要量化

计算过程中，**Tensor Core 与显存之间频繁进行数据交换**。
如果能减少数据交换的数据量，就能显著提高推理速度。
**量化（Quantization）**的核心思想是：

> 将浮点类型（FP32、FP16）的模型参数和激活值，用整数（Int8、Int4）来近似表示，同时尽可能减小误差。

---

## 2. 量化带来的好处

* 减少模型存储空间和显存占用。
* 降低显存与计算单元（Tensor Core）之间的数据传输量。
* 整数运算速度快于浮点运算，从而加速推理。

---

## 3. 对称量化（Symmetric Quantization）

![quant1](../using_files/img/llms/quant1.png)

```text
将浮点数映射到有符号整型范围（-127, 127），以0为中心对称。

公式：
scale = 127 / max(abs(x))
x_q = Clip(Round(x_f * scale), q_min, q_max)

反量化：
x_f' = x_q / scale
```

---

## 4. 非对称量化（Asymmetric Quantization）

```text
允许浮点数的原始范围 [Rmin, Rmax] 映射到整数范围 [Imin, Imax]，
不要求以0为中心对称。常用于无符号Int8（0~255）。

公式：
scale = (max(x_f) - min(x_f)) / (q_max - q_min)
zero_point = q_min - round(min(x_f) / scale)
x_q = Clip(Round(x_f / scale + zero_point), q_min, q_max)

反量化：
x_f' = (x_q - zero_point) * scale
```

---

## 5. 量化对精度影响小的原因

1. 权重和输入通常已被归一化，数值范围较窄；
2. 激活函数平滑化了量化误差的传播；
3. 神经网络依赖的是**相对数值关系**而非绝对值。

# 动态量化（Dynamic Quantization）

![dynaquant](../using_files/img/llms/dynamicquant.png)

### 核心思路

* **权重**：在部署前量化为 int8；
* **激活值**：推理时根据当前输入动态计算量化参数（scale、zero point）。

### 特点与流程

1. **无需校准数据**；
2. **推理时动态计算激活范围并量化**；
3. **权重量化参数固定**，激活量化参数随输入变化。

### 优点

* 不需要额外数据集，部署简单；
* 精度通常优于未量化模型的直接截断；
* 适合快速验证、CPU推理或原型测试。

### 缺点

```text
1. 每次推理都需重新计算激活量化参数，带来额外开销；
2. 每层计算结束后需转回FP32，占用显存带宽；
3. 加速效果有限。
```

# 静态量化（Static Quantization）

### 核心思路

* **在推理前，用校准数据提前确定量化参数（scale、zero point）**。
* 模型权重和激活值在推理时都直接使用量化后的整数形式。

### 实现手段

1. **后训练静态量化（PTQ）**

   * 利用少量代表性数据收集激活分布；
   * 统计每层的最小值和最大值，确定量化参数；
   * 推理时直接在整数域进行计算。
2. **量化感知训练（QAT）**

   * 在训练阶段插入伪量化节点；
   * 模拟量化误差，让模型学会抵抗量化损失；
   * 精度最高，但训练成本较大。

### 优点

* 推理速度快（完全整数计算）；
* 显存占用低，能耗低；
* 适用于GPU/TPU/NPU等硬件部署。

### 缺点

```text
1. 需要代表性校准数据；
2. 若校准数据分布与实际数据不同，误差会增大；
3. 实现复杂度高于动态量化。
```

---

## 静态量化典型扩展

### 1. 量化感知训练（QAT）

```text
在模型训练中加入伪量化节点，让网络学会容忍量化误差，
增强鲁棒性，使量化后精度更接近原模型。
```

### 2. LLM.int8

![llmint8](../using_files/img/llms/llmint8.png)

```text
将矩阵分解为两个部分进行计算，避免在大模型中“突现特征”（emergent features）损失。
优点：支持大模型的精度保留。
缺点：推理速度略慢。
```

### 3. QLoRA

![qlora](../using_files/img/llms/qlora.png)

```text
在LoRA微调时，将基础模型参数进行4-bit量化以节省显存。
分块量化：根据参数的正态分布进行block-wise 4-bit量化。
在前向与反向传播中，会动态反量化为BFloat16进行计算。
```

## 总结对比表

| 特性     | 动态量化       | 静态量化               |
| ------ | ---------- | ------------------ |
| 激活量化参数 | 推理时动态计算    | 校准数据预计算            |
| 权重量化   | 部署前量化      | 部署前量化              |
| 需校准数据  | 否          | 是                  |
| 推理速度   | 中等         | 快                  |
| 精度稳定性  | 中等         | 高（尤其是QAT）          |
| 实现复杂度  | 低          | 高                  |
| 典型用例   | CPU推理、原型验证 | 工业部署、边缘设备          |
| 扩展方案   | —          | QAT、LLM.int8、QLoRA |
